Set up two-factor authentication

Your account can open member records, so a password alone is not enough to sign in. You will also need a 6-digit code from an app on your phone. This takes about two minutes.

  1. Install Google Authenticator, Microsoft Authenticator or any authenticator app.
  2. Scan the code this page shows you.
  3. Type in the 6 digits the app shows, then save your recovery codes.

Scan this code

Open your authenticator app, add an account, and scan the code. If you cannot scan it, type in the key below instead.

Save your recovery codes

Each code works once. They are the only way back in if you lose your phone, and this page cannot show them again. Print them, or keep them in a password manager.
