PDF Toolkit

Merge, split, rotate, reorder, watermark and convert PDFs. Everything runs inside this browser — no file is uploaded, and nothing reaches the server or leaves this computer. That matters here: these tools get used on member documents, payment proofs and certificates.

What this cannot do

Stated plainly, because a tool that quietly does a worse job than expected is worse than one that says so.

Compression shrinks a PDF only by rewriting its structure. It cannot re-encode embedded images the way desktop software does, so a scanned document will barely shrink. Expect a few per cent, not ninety.
Office conversion (Word, Excel, PowerPoint) is not here. It needs LibreOffice running on a server, which shared hosting cannot provide.
Password protection and unlocking are not here either. The library that does everything else in this page cannot encrypt or decrypt a PDF, and a button that silently produced an unprotected file would be dangerous.
