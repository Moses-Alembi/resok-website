Credential register

Which accounts exist, who owns each one, whether two-factor is on, and where the password is kept. No passwords are stored here — the secrets live in the password manager, and this links to them.

Why it works this way. Storing the domain, hosting and database passwords in this portal would put them on the same server as the key that protects them — one compromise would hand over all of it at once. A password manager is built for that job. What was actually missing was knowing which accounts exist and who holds them, and that is what this answers.
