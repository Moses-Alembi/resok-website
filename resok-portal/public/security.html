Two-factor authentication

A second factor on your own account, from an authenticator app. Your password can be guessed, reused or phished; a code that changes every thirty seconds cannot be any of those. This is the strongest single control available on an administrator account.

  1. Open Google Authenticator, Microsoft Authenticator or 1Password.
  2. Scan the code, or type the key below if the camera will not read it.
  3. Enter the six digits it shows, to prove the app is working before this is switched on.
Save these now. They are the only way back in if you lose the phone, and they are not stored anywhere they can be read again — only hashed, the same way a password is. Closing this page without keeping them means losing them.

Confirm with your password. A stolen session must not be able to quietly remove the control that would have stopped it.
